# Design and development of aircraft integrated control system (飞机综合控制设计与实践)

A project-based course in which students build, program, and test quadrotors through teamwork and independent problem-solving.
本课程以项目实践为主，学生通过团队协作与独立解决问题，完成四旋翼无人机的搭建、编程与测试。

## Student Projects (学生项目)

Projects are organized by year. Students in the each cohort should follow their own submission guidelines in the README of each folder.
项目按年份分类存放。各届学生请遵循对应年份文件夹中 README 的提交要求。
